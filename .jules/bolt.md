## 2026-10-28 - [Cache Intl Formatters]\n**Learning:** Instantiating new `Intl.DateTimeFormat` and `Intl.NumberFormat` instances on every render cycle (or using `.toLocaleDateString()` and `.toLocaleString()` which do the same under the hood) incurs significant performance overhead. Caching these formatters globally yields massive improvements when formatting long lists of dates or numbers.\n**Action:** Extract all `Intl` and `toLocale*` method calls into shared, statically instantiated global formatter objects wherever lists are dynamically rendered.
